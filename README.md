# 🎲 트위터 TRPG 시나리오 북마크 → Notion 자동 정리

트위터(X)에서 북마크한 TRPG 시나리오 트윗을 자동으로 수집하고,  
시스템별로 분류한 뒤 AI로 정보를 추출해 Notion 데이터베이스에 저장해주는 도구입니다.

---

## ✨ 무엇을 해주나요?

- 트위터 북마크를 한 번에 전부 가져옵니다
- TRPG 시스템 키워드 기반으로 자동 분류합니다 (CoC / inSANe / 시노비가미 등)
- AI가 시나리오 이름, 인원, 분위기, 개요를 자동으로 추출합니다
- 시스템별로 별도 Notion DB를 만들어 저장합니다
- 이후 실행 시 새로 추가된 북마크만 가져옵니다 (중복 없음)

---

|------|-----------|------|

## 🚀 설치 및 실행 방법

### Step 1. Python 설치

Python이 이미 설치되어 있다면 건너뛰세요.

1. https://www.python.org/downloads/ 접속
2. "Download Python 3.x.x" 버튼 클릭
3. 설치 파일 실행

> ⚠️ **중요:** 설치 화면 맨 아래 **"Add Python to PATH"** 체크박스를 반드시 체크하세요!

---

### Step 2. 파일 다운로드

이 페이지 오른쪽 상단 **Code → Download ZIP** 클릭 후 압축 해제

> ⚠️ **"안전하지 않은 파일" 차단 시:** 다운받은 zip 파일을 **우클릭 → 속성** → 하단 **"차단 해제"** 체크 → 확인 후 압축 해제

---

### Step 3. 최초 설정 (1회만)

압축 해제한 폴더 안에서 **`setup.bat`** 파일을 더블클릭하세요.  
순서대로 아래 항목들을 입력하라고 안내해줍니다.

---

#### 🐦 트위터 토큰 받는 방법

> 로그인 상태를 유지하는 쿠키 값입니다. 다른 사람에게 알려주지 마세요.

1. 크롬 또는 엣지 브라우저에서 **x.com** 로그인
2. **F12** 키 → **Application** 탭 → 왼쪽 **Cookies** → **https://x.com**
3. **`ct0`** 값과 **`auth_token`** 값을 각각 복사

> 💡 로그아웃하거나 비밀번호를 변경하면 토큰이 만료됩니다. `setup.bat`을 다시 실행해서 갱신하세요.

---

#### 📝 Notion 토큰 받는 방법

1. https://www.notion.so/my-integrations 접속 (Notion 로그인 필요)
2. **"+ 새 API 통합 만들기"** 클릭 → 이름 입력 → **제출**
3. **"내부 통합 시크릿"** 옆 **표시** 클릭 → 값 복사

---

#### 📄 Notion 페이지 ID 받는 방법

시스템별 DB들을 만들 Notion 페이지가 필요합니다.

1. 해당 페이지를 Notion에서 열기
2. 오른쪽 상단 **`...`** → **연결** → 방금 만든 통합 이름 클릭해서 연결
3. 브라우저 주소창 URL 맨 끝 32자리가 페이지 ID입니다:
   ```
   https://www.notion.so/페이지이름-abc123def456abc123def456abc123de
                                    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   ```

---

### Step 4. 실행

설정이 끝났으면 이후로는 **`run.bat`** 만 더블클릭하면 됩니다.

```
====================================================
  트위터 북마크 파이프라인
====================================================

  1. 북마크 수집     (트위터에서 새 북마크 가져오기)
  2. 분류            (TRPG 시스템별 자동 분류)
  3. AI 필드 추출    (시나리오 이름/인원/분위기/개요 자동 추출)
  4. Notion 업로드   (Notion DB에 저장)
  5. 전체 실행       (1 → 2 → 3 → 4 한 번에)
  6. 전체 재분류     (분류 결과 초기화 후 처음부터 다시)
  0. 종료
```

처음이라면 **5번 (전체 실행)** 을 선택하세요.  
이후에는 5번으로 주기적으로 실행하면 새 북마크만 추가됩니다.

## 📊 Notion DB 항목

각 시스템 DB에 저장되는 정보입니다.

| 필드 | 설명 | 채우는 방법 |
|------|------|-------------|
| 시나리오 이름 | 시나리오 제목 | AI 추출 |
| 배포 URL | 시나리오 배포 링크 | 트윗 첨부 링크 |
| 최소인원 / 최대인원 | PL 인원 수 | AI 추출 |
| 분위기 | 공포, 일상, 미스터리 등 (다중 선택) | AI 추출 |
| 개요 | 시나리오 1~2문장 요약 | AI 추출 |
| 원본 트위터 링크 | 원본 트윗 URL | 자동 |
| 이미지 | 트윗 첨부 이미지 | 자동 |
| 저장일 / 트윗작성일 | 날짜 정보 | 자동 |
| 리트윗수 | 인게이지먼트 | 자동 |

## 🤖 AI 필드 추출 (선택 기능)

시나리오 이름, 인원, 분위기, 개요를 AI가 자동으로 추출합니다.  
아래 중 **하나만** 있으면 됩니다 (우선순위 순):

| AI | 키 이름 | 발급처 |
|----|---------|--------|
| OpenAI | `OPENAI_API_KEY` | https://platform.openai.com/api-keys |
| Vertex AI | `VERTEX_PROJECT_ID` | GCP 콘솔 (gcloud CLI 인증 필요) |
| Gemini | `GEMINI_API_KEY` | https://aistudio.google.com/app/apikey |

`setup.bat`을 다시 실행하거나, `.env` 파일을 메모장으로 열어 직접 추가해도 됩니다:

```
OPENAI_API_KEY=sk-...
GEMINI_API_KEY=AIza...
VERTEX_PROJECT_ID=my-gcp-project
```

> Vertex AI 사용 시 `gcloud auth application-default login` 인증이 필요합니다.

## ❓ 자주 묻는 질문

**Q. "python은(는) 내부 또는 외부 명령..."이라는 오류가 떠요**  
→ Python 설치 시 "Add Python to PATH"를 체크하지 않았습니다. Python을 재설치하세요.

**Q. 북마크가 안 가져와져요 / 토큰 오류가 나요**  
→ 트위터 로그아웃 후 재로그인하면 토큰이 바뀝니다. `setup.bat`을 다시 실행해 갱신하세요.

**Q. Notion에 업로드가 안 돼요**  
→ Notion 페이지에 Integration이 연결되어 있는지 확인하세요. (페이지 `...` → 연결)

**Q. 기존 북마크가 또 올라가요**  
→ `uploaded_ids.json` 파일이 삭제되면 업로드 기록이 사라집니다. 이 파일을 지우지 마세요.

**Q. AI 추출 없이 업로드하면 어떻게 되나요?**  
→ 시나리오 이름에 트윗 앞 50자가 들어가고, 인원·분위기·개요는 비어있는 채로 업로드됩니다. 나중에 AI 추출 후 재업로드는 불가하므로, 가능하면 추출 후 업로드하세요.

## 📂 파일 구성

```
trpg-bookmark-notion/
├── setup.bat                  ← 최초 설정 (1회만 실행)
├── run.bat                    ← 매번 실행할 파일
├── setup_wizard.py            설정 마법사
├── run_menu.py                실행 메뉴
├── bookmark_sync.py           트위터 북마크 수집
├── classify_bookmarks.py      TRPG 시스템별 분류
├── reclassify_ai.py           AI 필드 추출 (OpenAI/Vertex/Gemini)
├── setup_and_upload.py        Notion DB 생성 & 업로드
├── trpg_systems.json          시스템 정의 & 키워드 설정
│
│   ← 아래는 실행 후 자동으로 생성됩니다 (건드리지 마세요)
├── .env                       입력한 토큰 저장
├── bookmarks.jsonl            수집된 북마크
├── classified_bookmarks.jsonl 분류 완료된 북마크
├── uploaded_ids.json          Notion 업로드 기록 (지우면 중복 발생)
└── notion_db_ids.json         생성된 Notion DB ID 목록
```

## ⚠️ 주의사항

- 이 도구는 트위터의 내부 API를 사용합니다. 트위터 정책 변경에 따라 동작이 중단될 수 있습니다.
- 트위터 토큰(`ct0`, `auth_token`)은 계정 접근 권한과 동일합니다. `.env` 파일을 타인에게 공유하거나 GitHub에 올리지 마세요.
- 개인 사용 목적으로만 사용하세요.
